# DREAMLAB

Laboratório visual para criar e testar protótipos.

## DREAMLAB 0.2
- projetos locais e múltiplas telas
- canvas visual responsivo para celular
- texto, botão, bloco e imagem
- movimentação por toque ou mouse
- inspector com posição, tamanho, tipografia, cores, fundo, borda, raio, opacidade e sombra
- duplicação e organização de camadas
- desfazer/refazer
- botões com navegação entre telas
- prévia navegável do protótipo
- zoom e ajuste automático do canvas
- exportação e importação em JSON
- armazenamento local
